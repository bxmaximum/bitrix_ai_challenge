# Единый промпт прогона

Копируется в приложение дословно, без дополнений. Один и тот же текст для всех связок.

---

```
Прочитай файл TASK.md в корне проекта и выполни задание полностью.

Правила:
1. Работай автономно и не задавай вопросов. Все допущения, вопросы и осознанные
   отклонения от ТЗ фиксируй в файле SOLUTION.md в корне проекта — секции
   Reference и Assumptions / Questions / Deviations (лимит — в TASK.md).
2. Раздел «Контракт» в TASK.md обязателен к точному исполнению. TASK.md и AGENTS.md
   не изменяй.
3. Интернет доступен и нужен: дизайн-референс, свободные стоки, документация.
   Но готовые шаблоны лендингов и чужой код целиком не переиспользуй —
   вёрстка и код должны быть написаны тобой.
4. Закончив, сверь решение с контрактом и остановись.
```
