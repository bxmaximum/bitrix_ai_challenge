# SOLUTION

## Reference

**URL:** https://venetianspa.ca — «Venetian Nail Spa» (Awwwards, Honorable Mention, май 2026).

**Почему он.** Это премиальный бьюти-лендинг ровно про маникюр: одна золотая палитра, высококонтрастный дисплейный гарнитур, «арочная» геометрия и движение, которое строится на скролле, а не на тяжёлом WebGL — его можно воспроизвести чистым CSS/JS. Страница по ритму близка к нашей задаче: хиро → услуги → галерея → отзывы → форма → подвал. (Первым кандидатом был Base Coat Nail Salon — он закрыт Cloudflare-проверкой на бота, обходить её я не стал.)

Референс пройден целиком в реальном Chrome на десктопе (1440) и на мобильной ширине (375).

### Шрифты и палитра

- **Шрифты референса:** Beautique Display (платный дисплейный антиква, заглавные, ~65px в H1 / 55px в H2, лёгкий отрицательный трекинг) и Inter (13px, трекинг −0.2px). **У меня:** Cormorant Garamond 500 (ближайший свободный аналог; есть кириллица) для заголовков, меню и кнопок + Inter 400/500 для текста; всё локально в `fonts/*.woff2`.
- **Палитра:** золото `#b69f64`, кремовый фон `#ece8df`, песочный `#cdc4b0`/`#d9d0bc` (карточки отзывов), белый. Кнопки-«пилюли»: радиус 30px, `padding ≈ 11/29px`, переход цвета 0.75s и фона 0.65s, на hover — заливка.

### Воспроизведённые приёмы

1. **Хиро с «шторкой»:** золотые вертикальные полосы разрастаются сверху вниз по мере скролла с задержкой слева направо, затем кремовая арка наезжает на фото.
2. **Посимвольное проявление заголовков** (scrub по скроллу) — `data-split`; для скринридера задаётся `aria-label`, буквы в `aria-hidden`.
3. **Закреплённые секции** (`position: sticky`): центральный заголовок стоит, арочные фото и арочные карточки отзывов плывут мимо с разной скоростью.
4. **Язык «арки»:** скругление 300px у секций и подвала, арочные фото (`border-radius: 999px 999px 0 0`), арочные карточки.
5. **Пилюли и стрелки:** контурные кнопки с плавной заливкой на hover/focus, круглые стрелки каруселей, карточки услуг с медленным zoom фото на hover.

## Assumptions / Questions / Deviations

**Развёртывание свежей копии одной командой:**
`php www/bitrix/modules/sprint.migration/tools/migrate.php up` — инфоблоки и контент, установка `bxmax.booking` с расписанием на 14 дней, привязка шаблона к `s1`. Проверено полным откатом и повторным накатом.

**Допущения**
- «Ближайшие 14 дней» — сегодня и 13 следующих; слоты 10:00…19:00 (последний кончается в 20:00). Ежедневный агент поддерживает горизонт. Прошедшие слоты API отдаёт как `taken`.
- `MASTER_ID`/`SERVICE_ID` — ID элементов инфоблоков без внешних ключей; соответствие мастера и услуги не проверяется.
- Порядок проверок `create`: `CONSENT_REQUIRED` → `VALIDATION` → `SLOT_NOT_FOUND` → `SLOT_TAKEN`. Принимаются form-data и JSON; согласие — `1/Y/true/on`.
- Занятость слота — наличие заявки (уникальный индекс `SLOT_ID` + `SELECT … FOR UPDATE`); закрытие — флаг `IS_CLOSED`. Удаление заявки освобождает слот.
- Письмо уходит через очередь события `BXMAX_BOOKING_NEW` на e-mail из настроек модуля, иначе на `main:email_from`.
- Отзывы, галерея и контакты (адрес и телефон вымышлены) лежат в разметке страницы, а не в инфоблоках.

**Отклонения**
- Методы API без CSRF-токена и авторизации: запись публична, а токен ломал бы вызовы вне страницы. Защита — валидация и блокировка слота в БД.
- Палитра чуть темнее референса для текста и заливок (контраст WCAG AA); в подвале текст тёмный, а не белый.
- Beautique Display платный — заменён на Cormorant Garamond.
- Lenis/GSAP не использовались: пины и появления написаны на `sticky` и `requestAnimationFrame`. При `prefers-reduced-motion` и на <768px — статичная раскладка.
- Удаление заявки в админ-списке подтверждается штатным `confirm()` Bitrix.
- Фото — Unsplash (лицензия Unsplash), сохранены локально.
