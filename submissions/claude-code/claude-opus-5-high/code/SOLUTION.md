# SOLUTION — лендинг студии маникюра «Лак&Точка»

## Reference

**URL:** <https://venetianspa.ca/> — Venetian Nail Spa, Виннипег (Awwwards Nominee).

**Почему он.** Это лендинг реальной студии маникюра — та же задача, что у нас: длинная
одностраничка, которая должна унести на себе услуги, галерею, отзывы и форму и при этом
не потерять воздух. Его язык собран из вещей, которые честно воспроизводятся ванильными
CSS и JS — никакого WebGL и физики: арочные маски, побуквенное проявление гигантских
антиквенных заголовков, плавающие карточки, золото по кремовому. И он показывает, как
выглядит дорогая ниша, не скатываясь в «глянцевый шаблон салона красоты».

### Шрифты и палитра

- **Дисплейный.** Референс — `Beautique Display` (коммерческий, без кириллицы). Взят ближайший
  свободный аналог: **Playfair Display** — тот же высокий контраст штриха и острые тонкие
  засечки, есть кириллица. Используется так же: верхний регистр, `letter-spacing: -0.004em`,
  `line-height: 1.09`, размеры 90 / 65 / 55 px по референсу (у нас — `clamp()` от них).
- **Текстовый.** У референса и у нас — **Inter**, 400–600.
- Оба шрифта переменные, лежат локально (`woff2`, кириллический и латинский сабсеты).
- **Палитра** снята с референса: золото `#B69F64` (текст заголовков, обводки, футер),
  тёмное золото `#96814B`, кремовый фон `#ECE8DF` и `#F6F4EE` (чередование секций),
  тёплый серо-бежевый `#CEC6B3` (карточки, плейсхолдеры), текст `#333`, белый.

### Приёмы, которые воспроизводятся

1. **Побуквенное «зажигание» заголовков.** Дисплейные заголовки разбиваются на слова и буквы;
   по мере прохода секции буквы слева направо переходят из бледного тона в золото. Прогресс
   считается от положения заголовка во вьюпорте, а не по таймеру. Заголовок первого экрана
   зажигается сразу после загрузки.
2. **Арочная маска.** `border-radius: 50% 50% 0 0 / 42% 42% 0 0` — фото интро, плавающие фото
   в блоке о студии, портреты мастеров, карточки отзывов. Тот же приём в стыке секций: кремовый
   блок «вырезан» аркой поверх героя, а золотой футер скруглён сверху.
3. **Плавающие карточки с параллаксом поверх гигантского заголовка.** Арочные фото и карточки
   отзывов раскиданы по краям секции, смещаются при скролле с разной скоростью и частично
   перекрывают заголовок — как в «EVERY DETAIL» и «FIVE-STAR REVIEWS».
4. **Размытый монограммный вотермарк** за секцией (у референса — знак «V.», у нас «Л&Т»):
   огромный кегль, `blur`, непрозрачность 7 %, свой коэффициент параллакса.
5. **Состояния наведения и фокуса.** Pill-кнопки заливаются золотом снизу вверх
   (`transform: translateY(101%) → 0`); ссылки навигации подчёркиваются линией, растущей слева;
   карточки услуг увеличивают фото и раскрывают описание; круглые стрелки каруселей
   заливаются и слегка увеличиваются. Всё уважает `prefers-reduced-motion`.

## Assumptions / Questions / Deviations

**Развёртывание.** Свежая площадка приводится в рабочее состояние одной командой:
`php bitrix/modules/sprint.migration/tools/migrate.php up` — пять версий подряд ставят модуль
`bxmax.booking`, создают инфоблоки `services`/`masters` со свойствами, заливают 7 услуг и
4 мастеров вместе с картинками (лежат в `local/php_interface/migrations/media/`), генерируют
расписание и назначают сайту шаблон `laktochka` и имя «Лак&Точка». Расписание можно
догенерировать отдельно: `php bitrix/bitrix.php bxmax:booking:schedule --days=14` (идемпотентно).

**Контракт, крайние случаи.**
- `slots.list` с пустым или некорректным `weekStart` отдаёт текущую неделю: в контракте кода
  ошибки для этого нет, а падать на этом не хочется.
- Прошедшие слоты и слоты, закрытые администратором, отдаются со `status: "taken"`; попытка
  записи на них — `SLOT_TAKEN`. Новых кодов ошибок не вводил.
- Успешный `bookings.create` возвращает ровно `{bookingId}`. Экран успеха собирает детали из
  того, что посетитель уже выбрал на странице.
- Оба действия требуют `sessid` (штатный CSRF-фильтр ядра); фильтр аутентификации снят —
  запись доступна гостям.

**Гарантия «один слот — одна запись»** — уникальный индекс `UX_BXMAX_BOOKING_ENTRY_SLOT`
по `SLOT_ID`. Вставка ловит `SqlQueryException` и превращает её в `SLOT_TAKEN`. Проверено:
из 12 одновременных процессов на один слот успешным оказывается ровно один.

**Отклонения и решения.**
- `Beautique Display` из референса платный и без кириллицы — заменён на Playfair Display (OFL).
- Инфоблокам задан `API_CODE` (`Services`, `Masters`): без него не собирается D7-сущность.
- Страницы админки — двухстрочные стабы в `/bitrix/admin/`, весь код в `/local/modules/`.
  Это штатное соглашение Битрикса: `/local/admin/` ядро не сканирует. Удаление модуля стабы снимает.
- Компонент формы копируется установщиком в `/local/components/bxmax/booking.form` и удаляется
  при деинсталляции. Лендинг подключает его только если модуль установлен, иначе показывает
  телефон — поэтому после удаления модуля стенд остаётся рабочим.
- Получатель письма — опция модуля `admin_email` (Настройки → Настройки продукта → Настройки
  модулей → Лак&Точка); по умолчанию берётся `main.email_from`.
- Отзывы — статический контент шаблона: ТЗ инфоблок под них не требует.
- Фотографии — Unsplash (Unsplash License), сохранены локально и уменьшены под задачу.
