## Итого

Впечатление решила точность воспроизведения референса: поставленные рядом, лендинг и venetianspa.ca читаются как одна страница, вплоть до совпадающих координат секций и купола. Главный плюс бэкенда — честная битриксовая архитектура: штатный Migration API ядра, контроллеры на атрибутах, Result/Error, админка на CAdminUiList с фильтрами и правами. Гонку закрывают индекс и блокировка, это подтверждено параллельными запросами. Главный минус — мелкие недоделки по краям: 1 px горизонтального скролла на 360, пустая последняя неделя календаря из-за часового пояса, неровный стиль кода вне lib. В SOLUTION.md не описано решение гонки.
