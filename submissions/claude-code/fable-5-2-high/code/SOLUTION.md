# SOLUTION

## Reference

**URL:** https://venetianspa.ca/ — Venetian Nail Spa (awwwards: https://www.awwwards.com/sites/venetian-nail-spa, Honorable Mention, 23.05.2026).

**Почему он.** Это та же ниша, nail spa, и секции референса почти один в один ложатся на секции из ТЗ. Страница держится на типографике, воздухе и трёх-четырёх приёмах движения, поэтому её можно повторить ванильным CSS/JS без WebGL и библиотек. Форма в конце страницы стоит на фото и собрана из белых скруглённых полей: в этот язык естественно встаёт виджет записи.

### Шрифты и палитра

- Заголовки, меню, кнопки: в референсе Beautique Display, платный, лицензии на кириллицу нет. У меня Cormorant (OFL, вариативный, 500), прописные, размеры 96 / 68 / 46 px вместо 90 / 65 / 55: Cormorant у́же и светлее.
- Текст: Inter 15/20, как в референсе.
- Палитра референса: золото #B69F64, крем #ECE8DF, песок #CEC6B3, белый. У меня те же три цвета плюс два затемнённых золотых для текста, см. Deviations.

### Приёмы, которые воспроизведены

1. **Купол.** Следующая за хиро секция с радиусом 400 px (150 px на телефоне) выглядывает на 66 px внизу первого экрана и наезжает на хиро при прокрутке.
2. **Жалюзи.** Пока хиро уходит вверх, его закрывают вертикальные золотые полосы, слева они смыкаются в сплошную заливку.
3. **Закреплённый заголовок и всплывающие арки.** Две секции, галерея и отзывы: заголовок стоит на месте, арочные карточки проходят поверх него снизу вверх в шахматном порядке.
4. **Побуквенное проявление заголовков** по мере прокрутки. Скринридер читает заголовок целиком через `aria-label`.
5. **Кнопки и ссылки.** Пилюля с рамкой 1 px за 0,65–0,75 с заливается цветом рамки; у ссылок меню проявляется подчёркивание; шапка меняет фон и цвет текста после 40 px прокрутки; у стрелок карусели та же заливка.

При `prefers-reduced-motion` приёмы 2–4 отключаются, закреплённые секции становятся обычными сетками.

## Assumptions / Questions / Deviations

**Развёртывание.** Одна команда из `www/`: `php bitrix/modules/sprint.migration/tools/migrate.php up`. Шесть миграций ставят модуль, создают инфоблоки, контент с фото, расписание, назначают шаблон сайта и создают группу администраторов студии.

**Допущения**

- Слот равен визиту на час, длительность услуги на сетку не влияет. Все услуги в контенте укладываются в 60 минут, на этом построен оффер.
- Прошедший и закрытый слот отдаётся как `taken`; запись на него возвращает `SLOT_TAKEN`.
- У мастера есть список услуг (свойство `SERVICES`). Запись на услугу, которую мастер не делает, возвращает `VALIDATION`.
- Телефон только российский, хранится как `+7XXXXXXXXXX`.
- Письмо уходит на адрес из настроек модуля, если он пуст — на `email_from` главного модуля. Отправка через очередь `b_event`.
- Расписание со временем сдвигается, поэтому агент модуля раз в сутки дописывает слоты до 14 дней вперёд. В админке есть кнопка «Дополнить расписание».

**Отклонения**

- `bookings.create` оставил под стандартным CSRF-фильтром: нужен `sessid` или заголовок `X-Bitrix-Csrf-Token`. На ошибку `invalid_csrf` ответ отдаёт новый токен. `slots.list` работает без токена.
- `slots.list` с неверным `weekStart` возвращает `VALIDATION`, такого кода в контракте нет.
- Золото референса на креме даёт контраст 2,1:1. Для текста взял #8A7434 (заголовки) и #6B5925 (абзацы), вуаль на фото сделал плотнее. Декор остался #B69F64.
- Видео в хиро заменил фото с медленным дрейфом. Инерционную прокрутку (Lenis) не повторял.
- Сверх ТЗ добавил группу «Администраторы студии»: право W на модуль и чтение `/bitrix/admin`. Без второго не-администратор не откроет страницы модуля даже при праве на него.
- Откат миграции шаблона не снимает шаблон: сайт без шаблона через API не сохраняется.

**Вопросы**

- Нужны ли отмена записи самим клиентом и напоминание о визите? Сейчас заявку удаляет только администратор.
- Достаточно ли времени согласия или нужно хранить ещё версию текста политики и IP?
- Реквизиты студии (адрес, телефон, соцсети) вымышлены: какие подставить?
